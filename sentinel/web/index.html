{{ prettyCtx(logCtx) }}

其他网站可通过 上报令牌（在「上报令牌」页创建）向本系统推送日志与异常。接口支持 CORS，可直接在浏览器/服务端调用。

上报日志 POST {{ apiBase }}/api/v1/logs
curl -X POST "{{ apiBase }}/api/v1/logs" \
  -H "Authorization: Bearer <你的令牌>" \
  -H "Content-Type: application/json" \
  -d '{"source":"shop-site","level":"error","message":"订单接口 500","context":{"order_id":12345}}'
上报异常（触发 AI 诊断 + 邮件通知）POST {{ apiBase }}/api/v1/anomalies
curl -X POST "{{ apiBase }}/api/v1/anomalies" \
  -H "Authorization: Bearer <你的令牌>" \
  -H "Content-Type: application/json" \
  -d '{"source":"shop-site","severity":"critical","title":"支付服务不可用","detail":"连续 3 次调用支付网关超时"}
前端 JS 示例
fetch("{{ apiBase }}/api/v1/logs", {
  method: "POST",
  headers: { "Authorization": "Bearer <你的令牌>", "Content-Type": "application/json" },
  body: JSON.stringify({ source: "web-frontend", level: "warn", message: "CDN 加载超时" })
}).then(r => r.json());
